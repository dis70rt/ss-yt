Easy YouTube Downloader

Welcome!

This tool helps you download YouTube videos or get direct links to watch them. It's simple to use!

Just add some information to the website address (URL) and you're good to go.

How to Use It

The main way to use this service is by going to the /watch link. You'll need to add a question mark ? after /watch and then provide some details.

The most important detail is the Video ID.

  • Every YouTube video has a unique ID. For example, in the link https://www.youtube.com/watch?v=dQw4w9WgXcQ, the Video ID is dQw4w9WgXcQ.
  • You must include this using v=VIDEO_ID_HERE.

Parameters (Options You Can Add)

Here are the options you can use to customize your download or stream. You combine these with an ampersand & symbol (e.g., v=VIDEO_ID&q=720p).

Option What it does Example Values Default Needed?
v The ID of the YouTube video. e.g., dQw4w9WgXcQ N/A Yes
q Video quality. 1080p will download the file. Other qualities give a direct link to watch. 360p, 720p, 1080p 360p No
sub Include subtitles? (English only for now) true or false true No
media Get video (mp4) or just audio (mp3). Choosing mp3 will always download the file. mp4, mp3 mp4 No

Let's See Some Examples!

Imagine your service is running at http://your-website.com. You would add /watch? and then your options:

1. Get a link to watch a video in 720p:

http://your-website.com/watch?v=VIDEO_ID_HERE&q=720p

2. Download a video in 1080p with subtitles:

http://your-website.com/watch?v=VIDEO_ID_HERE&q=1080p&sub=true

3. Download just the audio (MP3) of a video:

http://your-website.com/watch?v=VIDEO_ID_HERE&media=mp3

4. Get a link for 360p video without subtitles:

http://your-website.com/watch?v=VIDEO_ID_HERE&q=360p&sub=false

What Happens Next?

  • For Downloads (1080p video or MP3 audio): Your browser will start downloading the file. The filename will be the video title.
  • For Stream Links (e.g., 360p, 720p video): You'll be taken directly to a page where the video plays (it's a direct link to the video stream).

Important: If you request 1080p video or an MP3 audio, the file is first downloaded to the server and then sent to you. This might take a moment!

If Something Goes Wrong

Sometimes things don't go as planned. Here's what an error might mean:

  • "Missing video ID": You forgot to add the v=VIDEO_ID_HERE part.
  • "File not found after download": The server tried to download the file for you (for 1080p/MP3) but couldn't find it afterwards. This could be a temporary issue.
  • Other errors ("Error: ..."): Something unexpected happened. It might be a problem with the video link or a temporary server hiccup.

If you see an error, double-check the Video ID and your options. Try again after a few minutes if it seems like a temporary issue.
